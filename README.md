<h1>Projeto realizado para entrega em aula do curso de Análise e Desenvolvimento de Sistemas ULBRA.</h1>

Criadas três classes de objetos em Java com NetBeans para demonstrar a funcionalidade da herança de classes, neste programa é possível criar objetos de Carro e Moto, com características, além disso, existe uma função que possibilita a visualização dos objetos.

<h1>Executar</h1>
Basta executar o arquivo com o nome de "gerenciador". É possível criar outros objetos seguindo o modelo já presente no código.
